# Assignment 2 - OOP

C# - ASP.Net Course

## Description

This project models an Employee for a company using OOP concepts (classes, properties, constructors, enums).

## Files

- **Employee.cs** - Employee class with Id, Name, SecurityLevel, Salary, HireDate and Gender.
- **HireDate.cs** - HireDate class with Day, Month and Year.
- **Enums.cs** - Gender enum (M, F) and SecurityLevel enum (Guest, Developer, Secretary, DBA).
- **Program.cs** - Creates an array of 3 employees (a DBA, a Guest, and a security officer with full permissions).

## Notes

- Salary is displayed in currency format using String.Format.
- ToString is overridden in Employee to display employee data as a string.
